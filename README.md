# Delivery Order System

Система для приема заказов на доставку.

## Запуск проекта

1. Клонировать репозиторий: git clone https://github.com/Nipton/TestTaskDelivery.git
2. Перейти в папку проекта: cd TestTaskDelivery
3. Запустить приложение: dotnet run
4. После запуска откройте адрес, указанный в консоли

При запуске приложения миграции базы данных применяются автоматически.

## Технологии

- ASP.NET Core MVC (.NET 9)
- Entity Framework Core
- SQLite
- Bootstrap 5
- Tom Select

## Функционал

- Создание заказа
- Просмотр списка заказов
- Детальный просмотр заказа
- Поиск городов с автокомплитом
- Редактирование заказа
- Валидация всех полей
- Автоматическая генерация номера заказа
